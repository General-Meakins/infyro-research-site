Agentic orchestration: Europe mid/large-cap impact basket

14 Companies
7 Exchanges

In 2026, digital procurement & supply chain environments move towards an end state of "autonomous enterprise" — a paradigm in which >50% of core industrial processing (procurement, payroll, logistics) is handled by agentic personnel (AI bots).

Where software harnessed robotic-type process automation (RPA) that followed strict rules, the approaching frontier is agentic-type (APA) "smart" decisioning, where reasoning occurs through exception.

In one example, an agent notices a shipping delay and autonomously re-negotiates a contract via an enterprise resource planning system (ERP).

We investigate this disruption across a full agentic software value chain, from hardware providers to the pure software layer, using a basket of 14 European large cap names as our test universe.
